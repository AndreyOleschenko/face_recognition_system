
# face_recognition_system
=======
# Система распознавания лиц для видеонаблюдения

Данный проект представляет собой программный комплекс на Python для автоматического распознавания лиц в видеопотоках с камер наружного наблюдения.

## Возможности

- Добавление известных лиц (загрузка фотографий)
- Поддержка USB-камер и IP-камер (RTSP)
- Разовое и автоматическое распознавание
- Веб-интерфейс для управления и мониторинга
- Журнал событий с экспортом в CSV
- Многопоточная обработка

## Установка

1. Клонируйте репозиторий
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте его и установите зависимости: `pip install -r requirements.txt`
4. Запустите приложение: `python app.py`
5. Откройте браузер по адресу `http://127.0.0.1:5000`

## Конфигурация

Основные параметры находятся в файле `config.py` (порог распознавания, пути, параметры камер).
